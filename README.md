# Combat Game

A simple text-based combat game made using OOP in C++ where players can attack and heal each other. Hope you enjoy stabbing people!

## Features

- Create player objects with unique names and stats
- Attack other players and reduce their health
- Heal players and restore health points
- Health limits to prevent values from going below 0 or above the maximum
- Demonstrates core OOP concepts:
  - Classes and Objects
  - Constructors
  - Member Functions
  - Encapsulation

## Technologies Used

- C++
- Standard Library (iostream, string)
